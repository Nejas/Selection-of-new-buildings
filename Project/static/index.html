    Правила формирования балла

    Нейтральная замена

    Если отдельный критерий недоступен, при расчёте используется нейтральное значение 0.5, а в карточке появляется предупреждение.

    Проблемный объект

    Если есть проблемный объект, итоговый статус не может быть выше “Рискованный”.

    Критическая задержка

    Если средняя задержка больше 180 дней, итоговый статус понижается на одну ступень.

    Недостаточно данных

    Статус “Неизвестный” ставится только если нет объектов или застройщик зарегистрирован менее года назад.
