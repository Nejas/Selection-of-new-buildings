# Подбор новостроек и оценка застройщиков

Приложение помогает подобрать новостройки с учётом доступности городской инфраструктуры и надёжности застройщика. Результаты отображаются на карте; для объекта можно открыть карточку застройщика и подробности его оценки.

## Возможности

- Выбор значимости объектов инфраструктуры и фильтра надёжности застройщика.
- Отображение подходящих новостроек на карте и просмотр карточки объекта.
- Расчёт оценки застройщика по данным об объектах, сроках, правовых событиях и репутации — при наличии исходных данных.
- Просмотр факторов оценки, проектов, правовых событий и новостей в досье.
- Поиск застройщиков и просмотр общей статистики в отдельном интерфейсе сервиса рейтинга.

Оценка зависит от полноты и актуальности исходных данных и не гарантирует отсутствия рисков. Досье по умолчанию хранится в кеше 24 часа; срок можно изменить через `DOSSIER_TTL_HOURS`.

## Запуск через Docker

Нужен установленный Docker с поддержкой Docker Compose.

1. Скопируйте пример конфигурации и задайте в `.env` уникальный пароль и ключ администратора источников новостей:

   ```powershell
   Copy-Item .env.example .env
   ```

   Откройте `.env` и замените оба значения-заполнителя. Для пароля PostgreSQL используйте латинские буквы и цифры.
2. Из корня проекта запустите сервисы:

   ```powershell
   docker compose up --build
   ```

3. Откройте приложение по адресу [http://localhost:3000](http://localhost:3000).

Подробности о настройках, пароле существующей базы и хранении данных — в [README-Docker.md](README-Docker.md). Команда `docker compose down -v`, приведённая в этой инструкции для пересоздания базы, удаляет данные в Docker volume.
