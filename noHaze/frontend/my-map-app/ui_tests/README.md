# UI-тесты Selenium

Тесты проверяют загрузку формы и карты, подбор объекта с фильтрами, открытие
карточки и досье, сброс, ошибку API и доступность основных элементов при ширине
окна 1440 и 390 пикселей. Дополнительно проверяются скрытие панели фильтров,
управление категориями, пустой результат поиска, повторное открытие карточки,
ошибка досье и повторный поиск после ошибки API. Сценарии основаны на пользовательских задачах из
[статьи Uplab](https://www.uplab.ru/blog/kak-i-zachem-provodit-ui-ux-testirovanie-sayta/).
Это функциональные проверки браузера: они не заменяют исследования с пользователями.

## Запуск в PowerShell

Нужны Python, Node.js и установленный Chrome. Selenium Manager может потребовать
доступ в интернет для загрузки подходящего драйвера браузера.

1. Остановите API noHaze: тестам нужен свободный локальный порт 8000. Они сами
   запустят на нём временный API с тестовыми данными и завершат его после проверки.
   Существующую базу данных тесты не используют. Не запускайте несколько копий
   тестов одновременно.
2. Из каталога `noHaze/frontend/my-map-app` установите зависимости:

   ```powershell
   npm install
   python -m pip install -r ui_tests/requirements.txt
   ```

3. В отдельном терминале из того же каталога запустите интерфейс:

   ```powershell
   npm start
   ```

4. Дождитесь сообщения о готовности интерфейса и в первом терминале запустите:

   ```powershell
   python -m unittest discover -s ui_tests -p "test_*.py" -v
   ```

Интерфейс должен открываться по адресу `http://localhost:3000`. Если он уже
запущен по другому адресу, задайте `$env:UI_TEST_URL` перед запуском тестов.
Адрес API пока зафиксирован в приложении: тестовый API всегда использует порт 8000.
После завершения остановите сервер интерфейса сочетанием Ctrl+C.
